# Dr. Enio Dionary - Advocacia de Trânsito

Landing page de alta conversão desenvolvida para o escritório de advocacia especializado em Direito de Trânsito em Foz do Iguaçu (PR).

## 🚀 Tecnologias Utilizadas

- **HTML5 Semântico**: Estrutura acessível e otimizada para SEO.
- **CSS3 Puro**: Estilização moderna com design responsivo, variáveis CSS e sem dependências externas.
- **JavaScript Vanilla**: Comportamento interativo dinâmico (FAQ accordion, menu mobile, rastreamento de eventos).
- **Google Tag Manager**: Integração para monitoramento e análise de conversões.

## 📁 Estrutura do Projeto

```text
├── assets/                  # Imagens e elementos gráficos da marca
├── css/
│   └── style.css            # Folha de estilos principal
├── js/
│   └── script.js           # Scripts de interatividade e métricas
├── index.html               # Página principal (Landing Page)
├── politica-privacidade.html# Página com termos de privacidade
└── .gitignore               # Regras de exclusão do Git
```

## 🛠️ Como Visualizar Localmente

Basta abrir o arquivo `index.html` em qualquer navegador web moderno ou utilizar uma extensão como o *Live Server* no VS Code.
